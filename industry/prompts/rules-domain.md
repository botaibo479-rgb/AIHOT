【投研领域翻译规则 — 本平台内容是加密、美股港股、黄金原油、外汇与宏观的市场资料，严格遵守】

1. 歧义默认值：以下词在中文有其他含义，**一律按金融市场含义翻译**：
   - Token = 代币（加密语境；不译“令牌”）
   - Perpetual / Perp = 永续合约
   - Funding rate = 资金费率
   - Open interest / OI = 未平仓合约（持仓量）
   - Basis = 基差
   - Liquidation = 强制平仓（爆仓）
   - Unlock / Vesting = 代币解锁 / 归属
   - Buyback = 回购；Burn = 销毁
   - Staking = 质押；Restaking = 再质押
   - Listing / Delisting = 上线交易 / 下架
   - Inflow / Outflow（ETF）= 净流入 / 净流出；Creation / Redemption = 申购 / 赎回
   - Yield = 收益率（债券语境）；Real yield = 实际收益率
   - Guidance = 业绩指引
   - Filing = 文件提交（法定披露）
   - Hawkish / Dovish = 鹰派 / 鸽派
   - Spot = 现货；Futures = 期货；Options = 期权
   - Whale = 大额持有者（不写“巨鲸买入”，转账不等于买卖）

2. 以下专有名词**一律保留英文原文或代码**，不翻译不加中文括注：
   - 代币代码：BTC / ETH / SOL / USDT / USDC / HYPE 等
     **规则**：任何代币、股票、ETF 代码一字不改（包括 .HK 后缀和数字代码如 0700）
   - 机构与报告缩写：SEC / CFTC / FOMC / OPEC+ / EIA / BLS / BEA / IMF / BIS / HKMA / SFC / 13F / 8-K / 10-Q / 10-K / Form 4 / S-1 / 19b-4 / COT
   - 指标缩写：CPI / PPI / PCE / GDP / PMI / NFP / DXY / VIX / TVL / APR / APY
   - 合约与基准：WTI / Brent / XAU / SOFR

3. 中国和香港机构**优先用官方中文名**：中国人民银行、香港金融管理局、香港证监会、香港交易所、国家统计局；美国机构首次出现可写中文名再括注缩写（如“美国证监会（SEC）”），后续保持一致。

4. 数字、单位、日期、URL **一字不改**保留：
   - 金额、数量、比例、区间必须保留原文的阿拉伯数字和单位；不要把 $1.2B 改写成“十多亿美元”
   - 基点（bp）、百分比、年化与否照原文
   - 日期照原文，原文没有时区的不补时区
   - URL 原样
